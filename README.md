# 语音输入（VoiceType）

按一下快捷键开始说话，松开后文字自动出现在当前光标处。为「打字慢、想口述写文章」的场景做的。

- 全局快捷键，任何程序里都能用
- 说完自动转成书面文字（去口水词、补标点）
- 自动贴到光标位置，**不动你剪贴板里的东西**
- 屏幕底部一个不抢焦点的小条显示状态

## 快速开始

```powershell
# 1. 安装依赖（已内置虚拟环境则跳过）
.venv\Scripts\python.exe -m pip install -r requirements.txt

# 2. 启动
.venv\Scripts\python.exe -m app.main
```

首次启动会弹出设置窗口，填好阿里云三项密钥即可。也可以先用离线假引擎验证链路：

> 设置 → 识别服务 → 勾选「使用离线假引擎」→ 保存。
> 此时按快捷键说话，会在光标处贴出一段写死的测试文字，用来确认热键、麦克风、粘贴全都正常。

## 阿里云密钥怎么拿

1. 开通[智能语音交互](https://nls-portal.console.aliyun.com/)，创建项目 → 得到 **AppKey**
2. 在 [RAM 控制台](https://ram.console.aliyun.com/) 创建一个子账号，只授予 `AliyunNLSFullAccess`
3. 为该子账号创建 **AccessKey ID / Secret**

三项都填进设置窗口，点「测试连接」验证。密钥用 Windows DPAPI 加密后存盘，
配置文件的副本拷到别的电脑上解不开。

计费：实时语音识别约 2~3 元/小时，按实际使用量计。

## 用法

| 操作 | 说明 |
|---|---|
| **点一下屏幕上的悬浮球** | 开始录音，再点一下结束并贴字（默认开启，可拖到任意位置） |
| `Ctrl+Alt+Space` | 同上，键盘入口（可在设置里改） |
| 悬浮球右键 | 设置、隐藏这个球、退出 |
| 托盘图标单击 / 双击 | 打开设置窗口 |
| 托盘右键 | 开始/停止录音、**显示悬浮球**（勾选项）、设置、重新加载配置、退出 |
| 再次双击 exe | 把已在运行的程序窗口叫出来（不会启第二个实例） |

悬浮球平时是半透明的，一时找不到它时，**右键托盘图标 →「显示悬浮球」**，
勾掉再勾上就能把它叫回来（和设置窗口里的开关是一回事，双向同步）。

**嫌三个键按着费劲就用悬浮球。** 键盘上好按的两键组合基本都被系统占了：
`Ctrl+空格` 是输入法中英切换、`Alt+空格` 是系统窗口菜单、`Shift+空格` 是全角半角，
`Alt+字母` 是各软件菜单栏的快捷键，剩下的就只有三键组合。悬浮球是不用记组合键的入口。

悬浮球平时半透明，鼠标移上去变实心；录音时变红并带呼吸光圈，中间变成"停止"方块。
**点它不会抢走你正在打字的地方**——这是靠 `WS_EX_NOACTIVATE` 实现的，
否则点球的瞬间焦点切给球，文字就会贴进空气里。

说话时底部小条会显示红点和计时；松手后显示「识别中」，贴完闪现「已写入」。

**按下快捷键的那一刻，小条就会立刻出现，不用等你开口**——不管有没有说话，
它都会先亮起来，同时响一声提示音。实测从按键到屏幕上看得见是 60 毫秒。
如果你按下去没看到它，那不是"还没开始"，是真的没生效，按上面「按快捷键没反应」那条排查。

程序启动时底部会飘出一条「已就绪」提示，同时托盘弹一条气泡。

这个程序常驻托盘运行，**没有主窗口**，关闭设置窗口不代表退出。
Win11 默认把新托盘图标折叠进任务栏的 `^` 里，建议点开 `^` 把话筒图标拖到任务栏常驻，
不然容易以为程序没开。

## 打包成 exe

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

产物在 `dist\VoiceType\`，**必须整个目录一起拷走**（onedir 模式，冷启动比单文件快）。
当前体积约 127 MB。

```
dist\VoiceType\
├── VoiceType.exe      4.7 MB   ← 只是启动器
└── _internal\         123 MB   ← 全部依赖都在这里
```

**单独把 exe 拷出来一定会挂。** 启动器要去找同目录的 `_internal` 加载 Python 运行时和 Qt，
缺了就是一句报错然后没影。放桌面、发给别人，都必须是整个文件夹。

### 放桌面

不要直接把 exe 拖到桌面——拖动是"移动"，会把 exe 从 `_internal` 旁边挪走，程序当场废掉。

1. 先把整个 `VoiceType` 文件夹放到一个固定位置（比如 `D:\Tools\VoiceType`），
   别留在项目的 `dist` 里，否则哪天清理构建产物就一起没了
2. 打开该文件夹 → 右键 `VoiceType.exe` → **发送到** → **桌面快捷方式**
   （或按住 **Alt** 再拖 exe 到桌面，Alt+拖是建快捷方式而不是移动文件）

### 发给别人

**你的密钥不会跟着走，可以放心发。** 配置在 `%APPDATA%\VoiceType\config.json`，
不在程序目录里；密钥还额外用 Windows 的 DPAPI 按当前用户加密（配置里 `enc:` 开头
那串就是密文），拷到别人电脑上解不开 —— 所以没人能刷你的阿里云账单。

**但对方拿到不能直接就用。** 默认配置里三个密钥是空的，第一次按录音时会弹出
「首次使用设置」窗口：里面写死了去哪个网址、点哪里、拿哪个值，要填的三个输入框
描了橙色边框，填完点「测试连接」显示成功再保存即可。

128 MB 直接发微信/邮件发不出去，先压个包（约能压到 40~50 MB）再走网盘或U盘。

## 常见问题

**双击 exe 没反应 / 以为没打开**
程序是托盘程序，**本身没有主窗口**。正常情况下双击后会弹设置窗口，并在屏幕底部飘一条
「已就绪」提示。如果只看到一闪而过或什么都没看见，多半是它已经在后台跑着了——
再双击一次 exe 会把已有窗口叫到前台，不会重复启动。要看它是否在跑，看任务管理器里有没有
`VoiceType.exe`，或看日志 `%APPDATA%\VoiceType\logs\app.log`。

**按快捷键没反应**
热键可能被微信、输入法、显卡驱动占用。托盘右键 → 设置 → 换一个组合键。
程序会在托盘气泡里提示注册失败的具体原因。

**文字贴到了错误的地方**
按下快捷键的那一刻，程序记下的是当时的前台窗口。请先点进编辑器让光标就位，再按快捷键。

**粘不上，或者只粘了一半**
设置 → 通用 → 把「粘贴等待」调大到 500 或 700 毫秒。大型 IDE 读剪贴板较慢。

**在管理员权限的程序里粘贴无效**
Windows 的 UIPI 机制禁止普通权限程序向提权窗口发送按键。需要用管理员身份运行本程序。

**识别有错字**
把常用术语加进阿里云热词表，把「热词表 ID」填到设置里，准确率提升最明显。
